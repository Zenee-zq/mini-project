# mini-project
My mini project i made is a terminal based Rock Paper Scissor game that i build using python
This is a offline game that is player with the computer 
The game has three modes
the modes doesn't change the rules of the game but dictate the conditions needed for one to win
first mode how i personally play the game as, the rounds as infinite and the person who scores three wins first is the winner of the game 
second mode is first person to score 5 wins is the winner 
third mode is that there is no conditions for winning and the mode is endless until he quits
